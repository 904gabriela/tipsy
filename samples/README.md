# Drop your files here

Put a few of your real files in this folder so the importer can be tested
against the actual things you own, not invented examples.

Useful:

- One or two `.json` lorebooks exported from SillyTavern
- One or two character cards — the `.png` images from Chub or Janitor
- Anything exported from Tipsy Chat or FictionLab
- A saved chat, if you have one you would want to carry over

Nothing here is uploaded anywhere. It stays on your computer and is
ignored by git, so it will never end up in a commit.
